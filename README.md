### 🚀 Installation

1. Install **Minecraft Java Edition 1.21.11**.
2. Install **Fabric Loader** for the matching Minecraft version.
3. Download **Fabric API** from this repository (or its official project page).
4. Download the mods you want from the collection.
5. Move the `.jar` files into your Minecraft `.minecraft/mods` folder.
6. Launch the game using the Fabric profile.

> **Important:** You do not need to install every file. Some mods are optional, while library/dependency mods are required by the mods that use them. Check each mod's documentation for its dependencies.

---

### ⚠️ Compatibility

- This collection is intended primarily for **Minecraft Java 1.21.11 with Fabric**.
- A few filenames refer to other Minecraft versions (for example, 1.21.9, 1.21.5, or 1.21.10). Do not assume those files are compatible with 1.21.11 — check the mod's official release page before installing.
- Do not mix Fabric, Forge, and NeoForge builds.
- Keep backups of your worlds before changing your mod setup.
